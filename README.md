# Benjamin Stubbing

I'm an economist in Wellington, New Zealand. At the Treasury, I work in Analytics, Insights, and Modelling, where we use research and analysis to make trade-offs clearer for decision-makers.

On GitHub, I use R and Quarto to explore economic questions and write up the results with the data, code, and assumptions alongside them. My interests include New Zealand's long-run growth, technology, and what makes it easier to build things people need.
